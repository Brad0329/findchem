  Claude(Cowork·폰·PC)에 커스텀 커넥터로 붙인다. 결정은 plan_agent.md A-001(Dart·Cloud Run `asia-northeast3`·인증 없음·읽기 전용·이 세션에서 배포).

    도구 실행은 앱·웹과 **같은 `AssistTools.run`**, 설명·시스템 프롬프트는 `lib/assist/prompt.dart` — 두 번째 구현 금지

  - 범위 밖: 인증(get_msds를 올릴 때), A-004 계산 도구, 자동 배포, 캐시
- **수용 기준**

### A-004: 계산 도구 (작성수준 판정 · 예비시나리오 대상 산정)
- **설명**: 계획서 별지 제1호(작성수준 구분)와 장외평가 예비시나리오 대상 산정표의 **산술과 비교를 코드로** 한다 — 에이전트 암산 금지.
  원격 MCP 서버(A-001)에 도구 2개를 더한다. 규칙 원문 = 작성 규정 고시 제2026-19호(`assets/law/`) 제2조11·12의1·12의2, 제4조 → 별표 1,
  제23조 → 별표 2, 그리고 규정수량 고시의 별표 1 비고 2·별표 2 일반기준 가~다·별표 3 일반기준 가·별표 4 비고 3(`lib/assist/rules.dart`).
  - 구현 위치: 계산 `lib/calc/`(Flutter 없음), 도구 설명·입력 스키마도 `lib/calc/`. MCP `tools/list`는 F-008 도구 2개 뒤에 이 2개를 붙인다.
    앱·웹 `AssistTools`에는 넣지 않는다(F-008 화면 범위 밖 — YAGNI)
  - **규정수량은 호출자가 주지 않는다** — 물질은 `src`(별표2|별표3)+`no`(search_chemical 결과의 표·번호)로 받고 수량·함량기준은 번들 데이터에서 읽는다(지어낸 수량 차단)
  - **결정(2026-10-02 — D2·D4는 사용자가 가정대로 확정, 나머지는 가정. 전문가 확인용 해석·대안·갈리는 예는 `docs/expert_review_A004.md`)**:
    - D1 취급량(ton) = 설계용량(m³) × 비중(물=1). 혼합물도 **전체 혼합물 양**(함량을 곱하지 않는다 — 규정수량 고시 별표 4 비고 2 나, 작성 규정 별표 1 제3호).
      함량은 함량기준과 비교해 **포함/함량미만**만 가른다. 기상물질·보관시설처럼 용량×비중이 아닌 경우는 호출자가 `quantity_ton`과 산정 근거 문장을 준다.
      **사례 A 실측으로 확인**(2026-10-02, 서브에이전트 Drive 읽기 — 별지1 10행·산정표 12행 역산, 물질별 합 8건): 용량×비중, 함량 미곱, 가스는 충전량 직접 기재
    - 산정표 판정 표기는 사례 A를 따른다: `표준시설`(규정수량 이상) / `소량시설`(미만) / `함량미만` / `미대상`(저확산) — 고시 원문에 없는 실무 표기임을 응답에 적는다
    - D2 행 고르기 — 원문이 기계적으로 정하는 것만 코드가 한다: 유해성 구분 행(급성·만성·생태)은 **행마다** 함량기준을 넘는 설비의 양을 따로 합해
      그 행의 하위·상위와 비교하고, 가장 높은 판정을 물질의 판정으로 한다(별표 1 비고 2 '가장 작은 수량'과 같은 결과). 별표3 질산(제46호)처럼
      함량기준만 다른 행은 함량이 맞는 행 중 기준이 가장 높은 행. **원문이 성상 판단에 맡긴 것은 호출자가 정한다**: 용액·* 행(`ambient_liquid`),
      저확산 행(`low_diffusion`) — 해당 행이 있는 물질에서 값이 없으면 계산하지 않고 `selection_required`
    - D3 함량기준이 빈 행(용액·저확산·* 행)의 기준 = 같은 항목 다른 행의 숫자 함량기준 중 가장 낮은 것(별표 2 일반기준 나·다, `conditions.dart`와 같은 해석)
    - D4 별표 4 비고 3 나: 저확산 행(하위 400·상위 '-')으로 판정한 물질은, 상위 규정수량이 있는 다른 물질과 함께 취급하면 작성수준 결정에서 뺀다(표에는 남기고 사유 표시).
      다른 물질의 평가 행에 상위가 하나도 없으면(예: 만성 40/- 행뿐) 빼지 않는다
    - 응답에 덧붙이는 안내(판정을 바꾸지 않음): 별표3 함량기준 미만이면 같은 CAS의 별표2 항목 안내, 2군이면 외부 비상대응 제외 가능(제6조①) 문장
    - 행 판별(용액·*·저확산)은 `conditions.dart`의 함수를 같이 쓴다. 빈 함량기준 해석은 `lib/calc/`에만 있고 F-008 condition 문장과 전 행 대조 테스트가 있다
    - D5 1군 정의의 '주요취급시설 운영'(규칙 제19조제8항)은 도구가 확인하지 않는다 — 1군 판정에 그 사실을 문장으로 붙인다
  - 범위 밖: 최하위 규정수량·R값(보관시설만 운영), 기상물질 운전조건 환산, 비중 조회(A-003 `get_msds` — 비중은 호출자가 넣는다), 사고시나리오(장외 영향 — KORA), 앱·웹 화면
