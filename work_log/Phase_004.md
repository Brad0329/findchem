# Phase 004: F-001 물질 검색 (완료일: 2026-09-11)

## 실패한 접근과 원인 ★
- **헤더 목업을 PNG 파일로 보내려고 헤드리스 Chrome으로 웹 빌드를 찍었다 → 실패.** `--headless=new`에서
  `--timeout`(실시간 대기)은 Flutter가 그리기 전에 빈 화면을 찍고, `--virtual-time-budget`(가상 시간)은 첫 프레임만
  찍혀 아이콘 폰트(⋮)와 팝업 메뉴가 안 나온다(예산을 40초로 늘려도 같음. SwiftShader `--use-angle=swiftshader`는
  필요 — 없으면 아예 빈 화면). 원인은 가상 시간에서 첫 프레임 뒤의 rAF 재그리기가 안 도는 것으로 보이나 확정은 못 했다.
  → 사용자가 목업 확인 없이 진행하기로 해서 스크립트(`scripts/shot_web.py`)와 개발 진입점은 지웠다.
  **다음에 화면을 파일로 남겨야 하면 Android 실기기 `adb shell screencap`(Phase 003 방식)이 확실하다.**
  Browser 패널 스크린샷은 AI만 보고 파일로는 안 남는다.
