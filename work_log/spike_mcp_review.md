### ★ 실행 규칙 (실패에서 배운 것) — **한 시나리오 = 한 대화**

첫 실행에서 B1~B3을 A1~A3과 같은 대화에서 던져 **판정 불능이 됐다.** 두 가지 오염이 있었다.

1. A1·A2가 이미 물질을 조회해 둬서 B 계열은 도구를 부를 필요가 없었다 → "호출 X"로 **오독**했다
   (기억으로 답한 것이 아니라 **앞 호출 결과 재사용**이었다)
2. A2 질문에 사용자가 **"암모니아(기체)"**라고 직접 써 둬서, B2의 "성상을 되묻는가"가 **원천적으로 측정 불가**였다

→ **질문마다 새 대화를 연다.** 단 절대 규칙은 아니다 — A1→A2→A3처럼 **맥락 이어받기 자체가 시험 대상**인
묶음은 한 대화에서 이어야 한다. 기준은 "한 문항 = 한 대화"가 아니라 **"한 시나리오 = 한 대화"**이고,
**다른 시나리오의 값이 대화에 남아 있으면 그 문항은 폐기**한다.

### 실패의 정체 — 숫자가 아니라 **빈칸**이다

세 종류로 정리된다.

1. **되묻지 않는다** (B1·B2) — 조건이 빠진 질문에 가정을 세우고 답한다
2. **설명 없는 필드를 무시하고 규칙을 지어낸다** (D3) — `priority`/`referenceNote` 불리언에 설명이 없었다
3. **원문에 없는 결론을 덧붙인다** (A2 "규정수량 이상 취급시설로 간주")

### 검증된 법칙 하나 — **설명한 필드는 쓰이고, 설명 안 한 필드는 버려진다**

- `legend`에 뜻을 적어 둔 **별표(\*)** → D2에서 정확히 해석, "(\* 비고 적용)"까지
- `legend`에 없던 **`priority`/`referenceNote`** → D3에서 무시되고 **그 자리를 지어낸 규칙이 채웠다**

이 대비가 아래 자산화 계획의 근거다. (처방 1차로 legend에 `priority`·`referenceNote`·`deleted`
설명을 추가해 커밋했다 — 커밋 `7e9b1a9`. **아직 재실행으로 검증하지 않았다.**)

### MCP 경로에만 있는 비용

새 대화마다 **도구 탐색이 1~2회 헛친다**(A1·D1·D2·D3에서 재현). 한국어 서술형 질의
("규정수량 조회 화학", "톨루엔 규정수량")로는 0건이고, **"findchem"이라는 이름**으로 검색해야 찾는다.
앱에 함수로 직접 걸면(= MCP 전송을 안 끼면) 탐색 단계 자체가 없어 생기지 않는 비용이다.

## 5. 자산화 변경 계획 (제안 — 새 세션에서 결정)

효과가 큰 순서. 각 항목에 **겨냥하는 문항**과 **트랙**을 함께 적는다.

### 제안 1. 표 밖 규칙을 자산에 넣는다 ★가장 효과가 크다

- **무엇**: 별표 2·3의 **일반기준(가·나·다)** 원문. 별표 4처럼 **텍스트 자산**이면 충분하다
- **겨냥**: D3(우선 적용), B1·B2(용액·함량 빈칸 해석)
- **트랙**: 번들 JSON을 안 건드리면 **저위험**. 원문 PDF는 이미 `assets/`에 있다
- **주의**: 손으로 옮긴 텍스트다 → `mcp_server.py --selftest`가 하는 **PDF 원문 대조**를 같은 방식으로 붙인다
- **선행 확인**: 일반기준이 별표 2·3 PDF의 표 **밖**에 있어 현재 파서가 건드리지 않는다. 옮겨 적기 전에 원문 위치를 확인할 것

### 제안 2. 행마다 "적용 조건"을 문장으로 붙인다

- **무엇**: 지금은 `kind:"용액", content:""` 같은 **표 조각**이라 사람이 읽어야 뜻이 산다.
  "수용액인 경우 적용", "함량 85% 이상일 때 적용", "함량 빈칸 = 가장 낮은 함량 적용"처럼
  **조건 문장**으로 바꾸고, 한 물질의 여러 행을 **배타적 선택지**로 제시한다
- **겨냥**: B1·B2 (조건을 인지해야 답할 수 있는 형태로 만들어 되묻기를 유도)
- **트랙**: 번들 JSON 형식을 바꾸면 **일반 트랙**(SCHEMA 게이트·마이그레이션 실측).
  응답 조립 단계에서만 만들면 저위험 — **어디서 만들지가 결정 사항이다**
- **대가**: 원문에서 파생한 문장 = **손으로 만든 데이터** → 원문과의 대조 테스트를 같은 커밋에(CLAUDE.md 불변 규칙)

### 제안 3. 커버리지를 응답에 선언한다

- **무엇**: "이 도구는 이 고시 **별표 2·3만** 덮는다. 여기 없으면 이 고시의 규정수량 대상이 아니다"를 항상 싣고,
  **0건**과 **부분 일치만 걸림**(아세톤 → 유도체 2건)을 서로 다른 명시적 상태로 돌려준다
- **겨냥**: C1, 그리고 사용자가 지적한 **"없으면 없다고 빠져나가게"**
- **트랙**: 저위험(응답 필드 추가). 스키마 무관

### 제안 4. 찾기를 강화한다 — 묶음 항목 해소

- **무엇**: CAS 없는 항목 **77건**(염류·"~와 그 화합물")이 지금 막다른 길이다. 공공데이터 API가 CAS로
  고유번호·물질분류를 돌려주므로(실측: 염화납 7758-95-4 → `97-1-9` '납과 그 화합물') 그것으로 번들 JSON을 되짚는다
- **겨냥**: CAS 0건 질문 일반
- **미해결**: `97-1-9`는 PDF에서 **21개 행이 공유**한다 → `contInfo`(구분·함량)로 행을 고르는 규칙이 더 필요하다
- **트랙**: 새 외부 호출 = **보안 3층 ②** 대상
