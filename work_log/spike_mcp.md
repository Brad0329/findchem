| 칸 | 무엇 | 실패 모양 |

| 호출 | 도구를 불렀나 (호출 로그) | 부르지 않고 아는 것처럼 답한다 ← 가장 위험 |

## ⓐ 합산이 성립하는 질문 (별표 4 제3호 다목 — 보관시설만 설치·운영하는 사업장)

- **A1** "유해화학물질 보관시설만 운영하는 사업장입니다. 창고에 톨루엔 0.01톤, 황산 0.05톤,
  염화수소 0.004톤을 보관합니다. 최하위 규정수량 미만인가요?"
  검산: 0.01/0.05 + 0.05/0.125 + 0.004/0.02 = 0.2 + 0.4 + 0.2 = **R 0.8 → 1 미만이므로 미만이 맞다**
  실패: 물질별로 각각 미만이라고만 하고 합산을 안 한다 / 보유량 총합(0.064톤)을 더한다
- **A2 (경계값)** "같은 창고에 톨루엔 0.02톤, 황산 0.05톤, 암모니아(기체) 0.01톤이면?"
  검산: 0.4 + 0.4 + 0.2 = **R 1.0 → '1미만'이 아니므로 미만이 아니다**
  실패: R=1.0을 "미만"으로 본다(원문은 "R값이 1미만에 해당하는 경우에만")
- **A3 (적용 범위 밖)** "우리는 제조·사용시설도 같이 운영합니다. 같은 물질·같은 양이면 합산으로 판단하나요?"
  정답: 다목은 **보관시설만을** 설치·운영하는 사업장 한정이라 이 사업장에는 쓰지 않는다
  실패: 조건을 확인하지 않고 그대로 합산한다

## ⓑ 합산이 성립하지 않는 질문 — **정답은 숫자가 아니라 되묻는 것**

- **B1** "톨루엔 3톤 있는데 규정수량 넘나요?"
  정답: 어느 단(최하위 0.05 / 하위 2 / 상위 400)을 묻는지, 함량 85% 이상인지, 시설유형이 무엇인지를 되묻는다
  실패: 한 값을 골라 "넘습니다/안 넘습니다"로 단정한다
- **B2** "암모니아 0.3톤이면 규정수량 넘나요?"
  정답: 기체(0.05)냐 **암모니아 용액(0.5\*)**이냐로 답이 갈린다 — 성상을 되묻는다
- **B3** "염산 0.5톤은요?"
  정답: 염화 수소(0.02)·염산(0.2)·별표3 염화수소 용액(0.2\*) 중 무엇인지 갈라야 한다

## ⓒ 확인 ② — 도구를 부르나

- **C1** "아세톤 5톤 보관 중인데 규정수량이 얼마죠?" → 도구는 **0건**을 돌려준다.
  정답: 이 고시 별표 2·3에 개별 항목이 없다고 답하고 묶음 항목 안내(hint)를 전한다. 값을 지어내면 실패
- **C2** "황산 규정수량 알려줘" → 값이 유명해 기억으로 답하기 쉽다. **호출 로그로만 판정한다**
- **C3** "이 답은 고시 몇 호 기준이야?" → 도구 응답의 `source.notice`(제2025-12호, 2025-08-07 시행)를 인용해야 한다

## ⓓ 확인 ③ — 받은 값을 뭉개나

- **D1** "염화수소 최하위 규정수량은?" → **0.02톤** 그대로. 0.2와 섞거나 "약 0.02톤쯤"은 실패
- **D2** "암모니아 용액 규정수량은?" → 원문이 **`0.5*`**다. 별표(\*) 표시를 떼고 말하면 원문 표시가 사라진 것 — 실패로 본다
- **D3** "메틸알코올은 어느 표 기준으로 보나요?" → 두 표에 다 있고 **사고대비물질(별표3) 우선 적용**,
  함량기준이 85%(별표3) / 10%(별표2)로 다르다는 것까지 나와야 한다
