## 모델 ★먼저 정하고 기록한다 (2026-09-16)

**질문에 답하는 모델은 데스크톱 Claude에서 선택된 모델이다** — 서버는 도구만 주고 모델을 정하지 않는다.
그런데 확인 ②(도구를 부르나)·③(값을 뭉개나)는 **모델 능력에 직접 걸리는 항목**이라, 한 모델에서 통과한 결과가
다른 등급에 그대로 전이되지 않는다. 그러므로:

- **앱에 쓸 모델로 돌린다.** 권고 순서 = Opus 5로 한 번(상한 확인) → 앱 후보 모델로 같은 질문 12개 한 번.
  차이가 나면 그 자체가 결론이다("이 기능에는 이 등급이 필요하다")
- 앱에서는 모델 ID를 우리가 지정한다. 2026-06-24 기준 현행 ID·가격(100만 토큰당 입력/출력):
  `claude-opus-5` $5/$25 · `claude-sonnet-5` $2/$10 · `claude-haiku-4-5` $1/$5
- **같은 모델이어도 데스크톱 Claude에는 자체 시스템 프롬프트가 있어 앱과 동일하지 않다** — 근사 전이다.
  앱에서는 시스템 프롬프트·도구 설명을 우리가 쓴다(`mcp_server.py`의 `instructions`와 도구 docstring이 그 초안)
- Flutter/Dart에는 공식 Anthropic SDK가 없어 앱은 raw HTTP로 부른다(`http` 패키지는 F-007에서 이미 의존성)

**돌릴 때마다 아래 기록 표 머리에 모델 이름을 적는다.** 안 적으면 나중에 결과를 해석할 수 없다.

## ⓐ 합산이 성립하는 질문 (별표 4 제3호 다목 — 보관시설만 설치·운영하는 사업장)

- **A1** "유해화학물질 보관시설만 운영하는 사업장입니다. 창고에 톨루엔 0.01톤, 황산 0.05톤,
  염화수소 0.004톤을 보관합니다. 최하위 규정수량 미만인가요?"
  검산: 0.01/0.05 + 0.05/0.125 + 0.004/0.02 = 0.2 + 0.4 + 0.2 = **R 0.8 → 1 미만이므로 미만이 맞다**
  실패: 물질별로 각각 미만이라고만 하고 합산을 안 한다 / 보유량 총합(0.064톤)을 더한다
- **A2 (경계값)** "같은 창고에 톨루엔 0.02톤, 황산 0.05톤, 암모니아(기체) 0.01톤이면?"
  검산: 0.4 + 0.4 + 0.2 = **R 1.0 → '1미만'이 아니므로 미만이 아니다**
  실패: R=1.0을 "미만"으로 본다(원문은 "R값이 1미만에 해당하는 경우에만")
- **A3 (적용 범위 밖)** "우리는 제조·사용시설도 같이 운영합니다. 같은 물질·같은 양이면 합산으로 판단하나요?"
  정답: 다목은 **보관시설만을** 설치·운영하는 사업장 한정이라 이 사업장에는 쓰지 않는다
  실패: 조건을 확인하지 않고 그대로 합산한다

## ⓑ 합산이 성립하지 않는 질문 — **정답은 숫자가 아니라 되묻는 것**

- **B1** "톨루엔 3톤 있는데 규정수량 넘나요?"
  정답: 어느 단(최하위 0.05 / 하위 2 / 상위 400)을 묻는지, 함량 85% 이상인지, 시설유형이 무엇인지를 되묻는다
  실패: 한 값을 골라 "넘습니다/안 넘습니다"로 단정한다
- **B2** "암모니아 0.3톤이면 규정수량 넘나요?"
  정답: 기체(0.05)냐 **암모니아 용액(0.5\*)**이냐로 답이 갈린다 — 성상을 되묻는다
- **B3** "염산 0.5톤은요?"
  정답: 염화 수소(0.02)·염산(0.2)·별표3 염화수소 용액(0.2\*) 중 무엇인지 갈라야 한다

### Opus 5 대조 (2026-09-16, 표본 1문항)

같은 B2 질문("암모니아 0.3톤이면 규정수량 넘나요?")을 **Claude Opus 5**로 던졌더니

  **암모니아 용액이면 최하위 0.5톤이라 넘지 않는다.** Sonnet 5가 감췄던 용액 행을 정면으로 다뤘다

- 한 발 더: "보관시설만 운영하며 다른 물질도 보유하면 **합산 판정(R = ΣQn/QLLTn)**을 따로 확인하라"

### F-008로 넘기는 설계 조건

1. **응답의 모든 필드에 설명을 붙인다.** D2(설명한 별표 → 정확히 해석) ↔ D3(설명 없는 불리언 → 무시하고
   규칙을 지어냄)의 대비로 검증됐다. **설명한 필드는 쓰이고 설명 안 한 필드는 버려진다**
2. **한 질의에 행이 둘 이상이면(성상·용액·구분) 되묻도록 강제한다.** 모델은 스스로 묻지 않는다(B1·B2)
3. **함량기준을 답에 반드시 포함시킨다.** 세 번 중 두 번 흘렸다(B1·B2) — 혼합물이면 판정이 뒤집힌다
4. **근거(연번·고시 번호)는 화면이 직접 렌더링한다.** 모델의 자발성에 맡기지 않는다
5. **"도구가 준 것 이상을 말하지 말 것"을 프롬프트에 박는다**(A2·D3 대비)
